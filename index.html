Link Check

Er linket ægte, eller er det phishing? Indsæt det og få svar med det samme.

⬇ Download udvidelsen

Virker i Chrome, Edge, Brave, Opera og Vivaldi

Sådan installerer du den
  1. Pak ZIP-filen ud (højreklik → Udpak alle).
  2. Åbn chrome://extensions (Edge: edge://extensions, Brave: brave://extensions).
  3. Slå Udviklertilstand til.
  4. Klik Indlæs upakket, og vælg mappen med manifest.json i.
  5. Klik på puslespilsikonet, og fastgør Phishing Tjek.

Link Check kigger kun på selve linket og åbner det aldrig. Den kan tage fejl, så vær altid forsigtig med links, du ikke forventede at få.
